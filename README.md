- ⚙️ **Systems Engineering**: Crafting robust tools in **C++**, **Go (Golang)**, and **Linux/Unix** low-level infrastructure.
- 🚀 **Vision**: Fusing cybersecurity resilience with sovereign AI systems and elegant software craft.
